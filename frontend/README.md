
## Getting Started

First, run the development server:

```bash
pnpm --filter frontend dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.


================================

# Design System with Ladle

```bash
pnpm --filter frontend ladle:dev
```

- A partir de frontend: 
```bash
pnpm ladle:dev ou pnpm ladle:dev -- --port 61000
```

Do monorepo: 
```bash
pnpm --filter frontend ladle:dev
```

De qualquer lugar: 
```bash
pnpm dlx ladle dev --port 61000
```

Open [http://localhost:61000](http://localhost:61000) with your browser to see the result.
