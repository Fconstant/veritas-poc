
## Getting Started

First, run the development server:

```bash
pnpm --filter frontend dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Design System with Ladle

```bash
pnpm --filter frontend ladle:dev
```

Open [http://localhost:61000](http://localhost:61000) with your browser to see the result.
